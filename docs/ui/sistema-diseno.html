9. Glosario ⓘ

El mark price se usa para disparar el stop.

Mark price — precio de referencia que calcula Kraken a partir de varios mercados. Se usa para liquidaciones y para disparar el stop del bot, porque es más estable que el último precio negociado y no lo mueve una sola operación aislada.
